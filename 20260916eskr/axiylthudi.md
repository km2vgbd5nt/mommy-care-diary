# 每月最高800元，国家发放养老服务消费补贴，这样申领→

> 更新时间：2026-09-16 (UTC+8)

根据《民政部、财政部关于实施向中度以上失能老人发放养老服务消费补贴项目的通知》（民发〔2025〕37号），为切实减轻失能老人家庭照护负担，2026年1月起，阳江市正式实施国家养老消费券政策。该政策面向60周岁以上、经评估为中度及以上失能的老年人，每月发放最高800元电子消费券，可用于居家、社区及机构养老服务。

**一、****谁能申领？******

1.年龄及户籍要求：年满60周岁及以上（80周岁以上高龄失能老人可优先申领）；

2.能力要求：经民政部门指定的第三方机构，按照《老年人能力评估规范》（GB/T 42195-2022）统一评估，达到中度、重度或完全失能等级；

3.特殊情况：正在享受特困人员供养、经济困难失能老年人集中照护服务补助等专项补贴的人群，目前规定暂不能重复享受此项补贴。

**二、****如何申领？******

**三、****如何使用？******

**1.****抵扣比例：**按服务费用的30%–60%抵扣，每人每月最高抵扣额度不超过800元。

**2.****服务范围****：******

（1）居家/社区服务：助餐、助浴、助洁、助行、助急、助医，以及康复护理、日间托养、上门探访、健康监测等14类服务；

（2）机构服务：长期入住或短期“喘息服务”相关费用。

**四、****温馨提示******

1.政策有效期至2026年12月，需尽快申请；

2.消费券当月领取，应当月使用，次月失效；

3.消费券仅限本人使用，逾期自动清零；

4.养老消费券和现有的长期护理保险、老年综合津贴并不冲突，可以同时享受；

5.阳江市中西医结合医院和市城东养老院可提供全流程业务办理和咨询服务。
